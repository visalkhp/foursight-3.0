Mapping rules
  • Valid LED numbers: 0–149.
  • LED count = End − Start + 1.
  • Overlapping zone ranges are allowed because the physical strip shares sections between terrain features.
  • River Shore is not a separate zone.
  • Send to Arduino writes all 11 ranges to EEPROM, so the mapping survives power loss.
  • Test Zone temporarily lights the selected range; Default Terrain restores all normal zone colours.
